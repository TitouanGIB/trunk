    La théorie, en clair
    
      
    

      
    
        
    
          
    L'idée en 30 secondes
    
          
    
            
    🏢Le switch = un bâtiment
    Tous les ordinateurs y sont branchés.
    
            
    🚪Un VLAN = une salle fermée
    On ne parle qu'aux gens de sa salle. Bleu = salle 10, orange = salle 20.
    
            
    🏷️Le trunk = un couloir partagé
    Les messages de toutes les salles y passent, chacun avec une étiquette de sa salle.
    
            
    🔀Le routeur = la porte entre les salles
    C'est le seul qui peut faire passer un message d'une salle à l'autre.
    
          
    
        
    

        
    
          
    1 · Qu'est-ce qu'un VLAN ?
    
          
    Un VLAN (Virtual LAN) découpe un switch physique en plusieurs switchs logiques.
            Chaque VLAN forme son propre domaine de broadcast : une trame de diffusion émise dans le VLAN 10 ne sort
            jamais vers un port du VLAN 20.
    
          
      
            
    • Sécurité : la comptabilité et les RH ne se « voient » pas en couche 2.
      • 
            
    • Performance : moins de broadcasts par segment.
      • 
            
    • Souplesse : on change un poste de VLAN par configuration, sans recâbler.
      • 
          
    
          
    En général, on associe un VLAN à un sous-réseau IP (ici VLAN 10 ↔ 192.168.10.0/24).

    Le trunk évite de tirer un câble par VLAN : un seul lien transporte tous les VLAN, le tag indiquant
            à chaque trame à quel VLAN elle appartient.
    
        
    

        
    
          
    3 · Anatomie d'une trame 802.1Q
    
          
    La norme IEEE 802.1Q insère 4 octets entre la MAC source et l'EtherType. Le FCS est
            recalculé ; la taille maximale passe de 1518 à 1522 octets.
    
          
    
            
    Préambule + SFD8 o
    
            
    MAC dest.6 o
    
            
    MAC source6 o
    
            
    Tag 802.1Q4 o
    
            
    EtherType2 o
    
            
    Données46–1500 o
    
            
    FCS4 o
    
          
    
          
    
            
    TPID0x810016 bits : « attention, tag 802.1Q »
    
            
    PCP3 bitsPriorité QoS (802.1p), 0 à 7
    
            
    DEI1 bitTrame éligible à l'abandon en cas de congestion
    
            
    VID12 bitsNuméro de VLAN : 1 à 4094 (0 et 4095 réservés)
    
          
    
        
    

        
    
          
    4 · Router-on-a-stick
    
          
    Un switch de niveau 2 ne peut pas faire passer une trame d'un VLAN à un autre : il faut router.
            Plutôt qu'une interface physique par VLAN, le routeur utilise une interface physique découpée en
            sous-interfaces :
    
          
      
            
    • G0/0.10 → encapsulation dot1Q 10 → passerelle 192.168.10.1
      • 
            
    • G0/0.20 → encapsulation dot1Q 20 → passerelle 192.168.20.1
      • 
          
    
          
    Le trafic inter-VLAN monte sur le trunk dans un VLAN et redescend dans l'autre : il traverse deux fois
            le même câble.

    6 · VLAN natif & bonnes pratiques
    
          
      
            
    • Le VLAN natif est le seul transporté sans tag sur un trunk (VLAN 1 par défaut).
              Il doit être identique des deux côtés.
      • 
            
    • Choisir un VLAN natif inutilisé (ex. 99) : cela limite l'attaque par double tagging (VLAN hopping).
      • 
            
    • Restreindre le trunk avec switchport trunk allowed vlan.
      • 
            
    • Désactiver DTP : switchport nonegotiate, et forcer mode access sur les ports utilisateurs.
      • 
            
    • Ports inutilisés : shutdown et placement dans un VLAN « parking ».
      • 
            
    • Ne pas utiliser le VLAN 1 pour les données ni l'administration.
      • 
          
    
        
    

        
    
          
    7 · Pour aller plus loin Expert
    
          
    
            
    VLAN hopping par double tag
    L'attaquant, placé dans le VLAN natif, envoie une trame avec deux tags. Le premier switch retire le tag externe
              (natif, donc envoyé sans tag sur le trunk) ; le second lit le tag interne et livre la trame dans le VLAN cible. Parade : VLAN natif inutilisé,
              ou vlan dot1q tag native.
    
            
    Usurpation de switch (DTP)
    Un port en dynamic auto/desirable peut négocier un trunk avec un poste malveillant et lui donner accès à tous les VLAN.
              Parade : switchport mode access + switchport nonegotiate.
    
            
    QinQ (802.1ad)
    Un opérateur empile un tag de service (TPID 0x88A8) devant le tag client (0x8100) pour transporter les VLAN
              de ses clients. Il faut un MTU ≥ 1526 octets sur le cœur.
    
            
    Trunk vers un hyperviseur
    Proxmox (bridge VLAN aware), ESXi (port group avec VLAN ID ou 4095) ou Hyper-V : un seul lien trunk, et chaque VM
              reçoit son VLAN. Le tag est posé par le vSwitch, comme ici par le routeur.
    
            
    VLAN privés (PVLAN)
    Ils isolent des hôtes dans un même VLAN et sous-réseau (ports isolated/community/promiscuous) : c'est le cas
              typique des DMZ et des hébergeurs.
    
            
    Dépannage méthodique
    Dans l'ordre : show vlan brief → show interfaces trunk (liste autorisée, VLAN natif) →
              show mac address-table vlan X → show ip interface brief → show arp → capture sur le trunk.
